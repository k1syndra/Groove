# Groove для Android

Groove — музыкальный плеер для Android с поиском по YouTube Music и Audius. Собирайте любимые треки в одном месте и настраивайте плеер под себя.

[Скачать Groove 0.1 Beta для Android](https://github.com/k1syndra/Groove/releases/download/v0.1-beta/Groove-0.1-beta.apk)

## Что умеет Groove

- **Плеер.** Добавляйте треки в очередь, слушайте в фоне и управляйте воспроизведением из уведомления.
- **Тексты песен.** Следите за словами по ходу трека, когда доступен синхронный текст.
- **Темы.** Выберите одну из шести готовых тем или настройте цвета и шрифты сами. Фон плеера может подстраиваться под обложку трека.
- **Медиатека и профиль.** Сохраняйте песни в «Любимое» и возвращайтесь к ним через историю. В профиле можно менять ник, описание и фото, а также выбрать одну любимую песню.

## Установка

Откройте скачанный APK на телефоне с Android 6.0 или новее. Если Android попросит, разрешите установку из этого источника.
